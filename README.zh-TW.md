# OBS 預覽區切換

[English](README.md)

收起 OBS Studio 原生預覽區，讓停駐視窗使用空出的版面。也可以獨立切換 OBS 的預覽渲染。

## 使用方式

在一般預覽模式下，開啟 **工具 → OBS 預覽區切換**：

- **隱藏／顯示預覽區**：收起或恢復主視窗中央區域（含來源工具列），維持原本的渲染設定。
- **停止／啟用預覽渲染**：切換 OBS 內建的預覽渲染，維持原本的版面。
- **隱藏預覽區並停止渲染**：同時執行兩項操作。如果是此外掛停止了渲染，顯示預覽區時就會恢復渲染；若另行切換渲染，以手動操作為準。

在 **設定 → 快捷鍵** 找到「OBS 預覽區切換：顯示／隱藏預覽區」。快捷鍵儲存在 OBS 目前的設定檔。每次啟動 OBS 都會顯示預覽區。進入 Studio Mode 時會恢復中央區域，外掛暫停操作，以保留 Preview、Program 和轉場控制。

## Windows x64 原型

首版以 Windows x64 的 OBS Studio 33 為目標，由 GitHub Actions Runner 建置，可在該次工作流程下載 Windows x64 產物。外掛會先辨識 OBS 預覽元件。若日後 OBS 改了內部介面結構，外掛會略過版面操作並記錄警告。安裝步驟見 [英文版](README.md#windows-x64-prototype)。

## 驗收

1. 在一般模式切換預覽區，確認停駐視窗填補空間且能操作，恢復後原生預覽可用。
2. 分別測試只停止渲染、只收起預覽區，以及同時執行兩項操作；確認恢復時保留原先已停用的渲染狀態。
3. 收起預覽區後進入 Studio Mode，確認 Preview、Program、轉場控制可用。退出後確認能再次切換。
4. 設定快捷鍵，重啟 OBS，確認快捷鍵仍有效，預覽區預設顯示。
5. 用測試畫面啟動 OBS A 的 Program 錄影及 DeckLink HDMI 輸出，在 OBS B 的 GC551G2 擷取畫面上觀察切換前、中、後的影像與聲音，確認沒有中斷。
